# Kafka Throughput Testing

The maintained Kafka-backed throughput procedure is now part of
[`../PERFORMANCE_TESTING.md`](../PERFORMANCE_TESTING.md).

Use `scripts/benchmarks/run_throughput_test.sh`; it generates deterministic
payloads, isolated topics and configuration, completion-based measurements, and
a structured result manifest.

Documents under `results/` are historical records rather than portable
performance targets.
