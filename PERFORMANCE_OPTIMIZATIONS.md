# Performance Optimizations

This former optimization report was retired on 2026-07-24 because it mixed
unverified estimates, historical measurements, and current implementation
status.

Use the maintained sources of truth:

- `docs/PERFORMANCE.md` — tuning guidance and optimization boundaries
- `docs/PERFORMANCE_TESTING.md` — reproducible benchmark methodology
- `docs/IMPLEMENTATION_STATUS.md` — verified implementation and test status
- `ROADMAP.md` — planned performance work

Historical benchmark artifacts remain under `docs/benchmarks/results/` and must
not be treated as a current baseline unless their environment and method match a
new run.
